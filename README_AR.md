# DrAli: عيادتك الذكية على الموبايل، بدون إنترنت

## شو فيه
- **ملفات المرضى:** الاسم أو رقم الإضبارة، العمر، الجنس، الهاتف، السوابق، الأدوية، التحسس، العمليات، ملاحظات.
- **الزيارات:** خط زمني لكل مريض. كل زيارة فيها الشكوى، والفحص، والعلامات الحيوية (مع السكر والوزن)، والتحاليل، والتشخيص، والعلاج.
- **المؤشرات:** منحنيات للضغط، والنبض، والسكر، والحرارة، والأكسجة، والوزن عبر الزيارات.
- **التحليل الذكي:** DrAli بيحلل الزيارة مع سوابق المريض وأدويته وزياراته القديمة، وبيعطيك يا "تشخيص مرجّح" مع كيف تأكده، يا "عدة احتمالات" مع شو تسأل أو تفحص لتحسم. وفيك تعتمد التشخيص المقترح بكبسة.
- **تحليل سريع:** لحالة بدون ملف مريض، مع سجل محفوظ.
- **وضع ليلي ونهاري:** حسب الجهاز أو يدوياً. ألوان هادية ومريحة للعين، وخط IBM Plex Sans Arabic.
- **الحماية:**
  - قفل بالبصمة أو رمز الجهاز.
  - البيانات مشفّرة على الجهاز (AES-256).
  - ما في إذن إنترنت أصلاً.
- **نسخ احتياطي:** ملف `.drali` مشفّر بكلمة سر، وفيك تسترجعه على أي جهاز.
- **تصدير PDF** لملف المريض كامل.

## البناء
عن طريق GitHub Actions، والطريقة نفسها اللي مشيت عليها:
1. ارفع كل ملفات المشروع على المستودع.
2. البناء بيبلّش لحاله.
3. نزّل `hakim-apk` من **Actions**، وبعدين **Summary**، وبعدين **Artifacts**.

> الخط بينزل تلقائياً وقت البناء. إذا ما قدر ينزّله، التطبيق بيشتغل بخط الجهاز.
